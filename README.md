# Alvo Capital — Operação Penha 142

Site institucional desenvolvido com Next.js para apresentar a operação imobiliária Penha 142 da Alvo Capital.

## 🚀 Tecnologias
- [Next.js 13](https://nextjs.org/)
- React 18
- TypeScript
- React Icons
- jsPDF para geração do memorando em PDF

## 📦 Instalação

```bash
npm install
```

## 🧑‍💻 Ambiente de desenvolvimento

```bash
npm run dev
```

O site ficará disponível em http://localhost:3000.

## 🧾 Geração de PDF
Na seção “Memorando”, informe o nome e o valor da cota para gerar automaticamente um PDF resumido da operação.
