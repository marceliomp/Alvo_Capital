# Alvo Capital — Operação Penha 142

Projeto Next.js que apresenta o site institucional da operação imobiliária Penha 142, com foco em captação de
investidores e conteúdo institucional completo.

## 🚀 Scripts

- `npm run dev` — inicia o servidor de desenvolvimento em `http://localhost:3000`
- `npm run build` — cria a versão otimizada para produção
- `npm run start` — executa o build gerado em ambiente de produção
- `npm run lint` — executa a verificação de lint do Next.js

## 📦 Dependências principais

- [Next.js 14](https://nextjs.org/)
- [React 18](https://react.dev/)
- Tipos TypeScript e ESLint configurados para desenvolvimento seguro e padronizado.

## 📁 Estrutura

```
app/
  layout.tsx      # Layout principal com fonte Montserrat e metadados
  page.tsx        # Página única com todas as seções do site
  globals.css     # Estilos globais, paleta e componentes base
```
